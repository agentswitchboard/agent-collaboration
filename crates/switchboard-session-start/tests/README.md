# Session start tests

The integration target drives the pure make-then-register reducer through its
public API. A Hegel history model asserts the saved stage and effects for the
ACP paths. Native cases require durable first-input evidence after allocation and
challenge restart before it arrives. Other deterministic cases cover stale replies, exact cleanup,
invalid reopened records and the Machine library's declared transition table.
These tests observe the reducer contract. Storage, adapter and real-link behavior
are exercised at their owning boundaries when wired.
